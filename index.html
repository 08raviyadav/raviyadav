Graphify — the fix that shipped on PyPI

Problem: MySQL/MariaDB CREATE TABLE statements with DEFAULT current_timestamp() were silently dropped — the SQL parser hit an ERROR node and threw away the whole table.

What I did: Traced it to the tree-sitter-sql grammar handling of the parenthesised default, fixed the root cause (not a workaround), and added regression tests proving the table now parses.

Result: Maintainer cherry-picked the fix into graphify 0.9.95 on PyPI — "cherry-picked to preserve your authorship." My commit is on upstream main.

💸

NepPay — payments that never double-charge

Problem: Payments in Nepal feel clunky compared to GPay/PhonePe — and a retried payment must never charge twice.

What I did: Built a Flutter app on Nepal's own rails (NEPALPAY QR, FonePay QR, NPI) with an EMVCo QR parser and a Node.js double-entry ledger backend — every payment carries an idempotency key, so a retry returns the same transaction instead of a second charge.

Result: A working V0 prototype, open source, with the retry-safety proven live: same key, same transaction, charged once.
